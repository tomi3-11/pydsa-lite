# pydsa-lite

A beginner-friendly Python library for learning data structures, algorithms, and Big-O complexity.

> **Project status:** Initial project setup. The library is being developed incrementally; APIs and documentation are not yet complete.

## Goals

- Teach concepts through readable Python implementations.
- Explain invariants, trade-offs, and time/space complexity.
- Keep core runtime dependencies in the Python standard library.
- Provide runnable examples and tests for every implemented feature.
- Publish beginner-focused documentation with MkDocs Material.

## Development

The project is being built in milestones. See [open issues](https://github.com/tomi3-11/pydsa-lite/issues) for the implementation plan and [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution workflow.

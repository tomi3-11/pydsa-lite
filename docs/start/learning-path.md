# Learning path

Work through these stages in order. Do not rush to advanced algorithms before you can reason about loops, collections, and complexity.

## Stage 1 — Python foundations

- Variables, conditions, loops, functions.
- Lists, tuples, strings, dictionaries, and sets.
- Mutability, references, slicing, iteration, and comprehensions.
- Exceptions and basic testing.

**Checkpoint:** solve small problems using loops and built-in collections without copying a solution.

## Stage 2 — Complexity and problem solving

- Big-O time and space.
- Counting operations and identifying dominant terms.
- Best, average, and worst cases.
- Input constraints and choosing an acceptable approach.

**Checkpoint:** explain why an approach scales, not just what its Big-O label is.

## Stage 3 — Core data structures

- Lists and dynamic arrays.
- Stacks and queues.
- Hash maps and sets.
- Heaps and priority queues.
- Linked lists as a concept; compare with Python's practical alternatives.
- Trees and graphs as abstract models and common representations.

**Checkpoint:** choose an appropriate built-in or standard-library tool for a given operation pattern.

## Stage 4 — Core algorithms

- Linear and binary search.
- Sorting and custom keys.
- Two pointers and sliding windows.
- Recursion and divide and conquer.
- Breadth-first and depth-first search.
- Greedy algorithms and dynamic programming.

**Checkpoint:** solve a problem, explain the invariant, analyze complexity, and test edge cases.

## Stage 5 — Practice and application

For each topic:

1. Explain the problem in your own words.
2. Work through a small example by hand.
3. State the invariant or key observation.
4. Write a straightforward solution.
5. Test empty, small, duplicate, and boundary inputs.
6. Analyze time and space.
7. Refactor only after correctness is established.

Use the playground for quick experiments, but run serious tests locally as well.

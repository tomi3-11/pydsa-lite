# Python DSA Learning Lab

Learn to solve problems by understanding the underlying idea, choosing the right data structure, and writing clear Python.

This is a learning resource, not another data-structures package. In practical code, we use Python's built-in types and standard library. From-scratch implementations belong in focused exercises where they help explain how something works.

## How to use this site

1. Follow the learning path.
2. Study the concept and its complexity.
3. Run and modify examples in the Python playground.
4. Complete exercises before reading their reference solutions.
5. Apply the idea to a small problem of your own.

## The core approach

| Learn | Use in Python |
|---|---|
| Dynamic array | list |
| Hash table | dict, set |
| Stack | list |
| Queue / deque | collections.deque |
| Priority queue | heapq |
| Sorted insertion / search | bisect |
| Graph representation | dict with list or set neighbors |
| Sorting | sorted(), list.sort() |

Understanding the concept matters more than memorizing an implementation.

## Interactive practice

The playground runs Python in your browser using Pyodide. The runtime is downloaded when you first run code; execution happens client-side. No account or backend is required.
